## What it does

Hatchet brings calling-context and other hierarchical performance data into a Python environment. It enables researchers to filter, transform, and compare profiles while preserving the structure of the application’s execution.

## My contributions

As a developer and maintainer of Hatchet, I added readers for profiling data, developed analysis features, and reviewed and approved pull requests. My work on automated programmatic analysis includes high-level methods for identifying load imbalance, hot paths, scalability bottlenecks, correlations, and causes of performance variability.

## Related research

**Automated Programmatic Performance Analysis of Parallel Programs** introduces Chopper, a high-level Python API for common performance-analysis tasks. It demonstrates these workflows across several parallel applications.
